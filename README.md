# raymond_hawaii_2024

Repository for: Herbivore diversity enhances consumption of invasive algae via sampling effects, not complementarity

Authors: Calla V. Raymond, Zackery Rago, José R. Paula, Elizabeth M. P. Madin, Mary I. O’Connor

Status: This repository contains the analytical code used to generate results and figures for a manuscript currently submitted for publication. 
A permanent archived version of this repository will be deposited in Zenodo upon manuscript acceptance.

Key scripts:
  01_no_choice_assays.R
  02_choice_assays.R
  03_BEF_experiment.R

Data availability: 
Data necessary to reproduce the results of this study will be archived in permanent, publicly accessible repositories upon manuscript acceptance. Data will be deposited in the Dryad Digital Repository. Researchers who wish to access the data prior to publication may contact the corresponding author (see contact information below).

Reproducibility:
Each script is self-contained and reproduces the statistical analyses and figures for the three main experiments presented in the manuscript: the no-choice feeding assays, the choice experiment, and the biodiversity–ecosystem functioning (BEF) experiment.
